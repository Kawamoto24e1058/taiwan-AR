# 衣装1 調査メモ（監修前・未確定）

## 写真から読み取れる構成
| 部位 | 特徴 |
|---|---|
| 頭飾り | 白い毛の冠＋立てた黒っぽい羽根1本、前面に花形ビーズ、両脇に多色ビーズの垂れ飾り |
| 肩・胸 | マゼンタ地に白いビーズ網の肩掛け、縁に多色の房 |
| 上衣 | 白（写真ではプリント入りTシャツ着用 → イラストでは無地の白に） |
| 腰 | ピンク・黄色の帯 |
| 前掛け | 緑のプリーツ、白いアイレットレースの裾 |
| スカート | 黒地、紺の水玉パネル、赤い縁取り、小さな花の刺繍 |
| 脚 | 白地に黒帯の脚絆、緑の毛糸の房 |

## 調査で分かったこと（出典は二次資料が中心。確定は監修者に）
- 阿美族は北部（南勢）・中部（秀姑巒、海岸）・南部（卑南、恆春）に分かれ、服飾は部落ごとの差が大きい。
- 白い毛の頭飾りに羽根を立てる形は、花蓮の阿美族の頭飾りの記述と一致する（年齢で「公主帽」「花冠帽」の区別あり）。
- 台東の阿美族は黒・白・桃色を好み、馬蘭阿美は色彩豊かで「霞披」（肩掛け）がある、という記述がある → 写真の肩掛けとの関係は要確認。
- 女性の脚絆は黒白、という記述あり（写真と一致）。
- 情人袋（alufo）は主に男性の装身具とされる。写真の腰の赤い袋の扱いは要確認。
- 表演用の服には他の部族の要素を混ぜた創作もある、という指摘あり → 「伝統衣装」と表記してよいか要確認。

## 監修者への確認事項
1. 部族名・地域（部落）名、各部の名称（族語・華語）
2. 年齢・未既婚などで形が変わる部位があるか（頭飾りなど）
3. 腰の袋・羽根の色や本数など、イラストで省略・単純化してよい部分
4. AI補助で作成した下絵の扱い
